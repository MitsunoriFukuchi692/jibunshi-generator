==========================================
🚀 セットアップコマンド
==========================================

1. ZIPファイルを展開
   unzip jibunshi-generator.zip

2. バックエンド セットアップ
   cd jibunshi-generator/backend
   npm install
   cp .env.example .env
   # .env に ANTHROPIC_API_KEY を追加

3. フロントエンド セットアップ
   cd ../frontend
   npm install

4. DB初期化
   cd ../backend
   npm run init-db

5. 開発サーバー起動
   # Terminal 1 - Backend
   npm run dev
   
   # Terminal 2 - Frontend
   cd ../frontend
   npm run dev

6. ブラウザでアクセス
   http://localhost:5173
